# Coding Guidelines - Compatibility Entry Point

This file is a compatibility entry point for shared skills and tooling. It does
not define coding conventions.

Read and apply the canonical guideline for every affected layer:

- [`frontend/`](./coding-guidelines-frontend.md)
- [`backend/`](./coding-guidelines-backend.md)
- [`infrastructure/`](./infrastructure-guidelines.md)

For cross-layer work, apply every affected layer's guideline together with
[`architecture-reference.md`](./architecture-reference.md) and
[`testing-guidelines.md`](./testing-guidelines.md). Also apply
[`security-guidelines.md`](./security-guidelines.md) and
[`ux-guidelines.md`](./ux-guidelines.md) when relevant.

Do not add or reconcile coding rules in this file. Update the appropriate
canonical guideline above instead.
